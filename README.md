# AfricanizeAI

A free tutorial site covering programming fundamentals, data structures & algorithms, computer vision, and applied AI — built with African builders, researchers, and creators in mind.

## What's covered

- **Data Structures & Algorithms** — arrays, binary search, linked lists, with explanations, complexity analysis, and runnable code examples.
- **Computer Vision** — how machines interpret images, core tasks (classification, detection, segmentation), and how CNNs work.
- **AI Use-Cases** — practical applications of AI in business (forecasting, automation, personalization) and in creative work (writing, visual art, music).

## Tech

Plain HTML/CSS/JS — no build step, no framework. Easy to read, easy to extend, and deployable as-is on GitHub Pages.

```
AfricanizeAI/
├── index.html          # homepage
├── articles/            # individual tutorial pages
├── css/style.css        # site styling
└── js/script.js         # small interactive bits (search box)
```

## Running locally

Just open `index.html` in a browser, or serve the folder:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
