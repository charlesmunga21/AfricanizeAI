Images as Data

A digital image is just a grid of numbers. A grayscale image is a 2D array of pixel intensities (0–255); a color image adds three such arrays, one each for red, green, and blue. A computer vision model never "sees" a picture the way a person does — it operates purely on this array of numbers.

# A tiny 3x3 grayscale image, as a computer would represent it
image = [
    [0,   128, 255],
    [64,  200, 90],
    [255, 30,  10],
]

0 is black, 255 is white, and everything in between is a shade of gray. A color (RGB) image is the same idea three times over — one grid for how much red is at each position, one for green, one for blue — stacked together.

This is the same idea as the multi-dimensional arrays submodule in the Arrays module: an image is a 2D (or 3D, with color channels) array, stored the same way any other array is, with the same row-major memory layout underneath.
