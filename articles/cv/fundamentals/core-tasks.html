Core Vision Tasks

"Computer vision" isn't one task — it's a family of related tasks that ask different questions about the same image, and get very different kinds of answers back.

  • Image classification — assign a label to an entire image ("cat" vs. "dog").
  • Object detection — find where objects are, drawing bounding boxes and labeling each one.
  • Semantic segmentation — classify every individual pixel, useful when you need exact object boundaries (e.g. separating crop from soil in a farm photo).
  • Object tracking — follow an identified object across video frames over time.
Detection and segmentation are easier to understand once you've watched them run. Real-Time Detection points your camera at the world and draws YOLO boxes and MobileSAM masks live, on-device — nothing there is a screenshot or a canned example.
