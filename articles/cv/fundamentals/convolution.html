How Convolution Works

Most modern vision systems are built on Convolutional Neural Networks (CNNs). Instead of connecting every pixel to every neuron (which would be enormous and ignore spatial structure), a convolution slides a small filter ("kernel") across the image, learning to detect local patterns — edges, textures, corners — which get combined into more complex shapes in deeper layers.

import torch.nn as nn

model = nn.Sequential(
    nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Conv2d(16, 32, kernel_size=3, padding=1),
    nn.ReLU(),
    nn.MaxPool2d(2),
    nn.Flatten(),
    nn.Linear(32 * 8 * 8, 10)   # e.g. 10 output classes
)

What a convolution actually computes

At each position, the kernel overlaps a patch of the input the same size as itself. Every overlapping pair of numbers gets multiplied, and all those products are summed into a single output number. Then the kernel slides one step over and repeats — producing an entire grid of outputs, the "feature map."

Visual model: slide the kernel yourself

This 3×3 kernel is a simple vertical-edge detector. Step through it and watch it slide across the 5×5 input, computing one output value per position — and notice the output lights up exactly where the input actually has a vertical edge (the boundary between the 0s and the 1s).
