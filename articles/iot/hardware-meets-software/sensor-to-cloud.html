From Sensor to Cloud

Take the exact scenario you described: a sensor buried in soil, reporting to a box in the field, which somehow ends up as a chart on a dashboard you check from your phone. None of the individual hops are exotic — you've met most of these ideas already, just wearing different clothes.

The chain

  1. Soil sensor — a probe reads a raw electrical property of the soil (often capacitance or resistance) and converts it into a moisture value.
  2. Meter box (datalogger) — a field enclosure, often solar-powered, that reads one or more sensors on a schedule, timestamps each reading, and holds onto it. Research-grade dataloggers from companies like Campbell Scientific and METER Group are the industrial version of this; it's the same "read and store" loop from the Sensors & Actuators submodule.
  3. Low-power radio link — out in a field, Wi-Fi and cellular towers aren't always reachable. LoRaWAN is a low-power, wide-area network protocol purpose-built for exactly this: license-free, long-range (kilometers, not meters), and stingy enough with power that a battery-run sensor can last years — at the cost of sending only small, infrequent messages.
  4. Gateway → Internet — a gateway receives the radio transmission and hands it onto the ordinary internet. From here, it's just packets, hopping across routers exactly like the Networking Basics module described — the "last mile" was special, nothing after it is.
  5. Cloud dashboard — a server receives the data, stores it, and a dashboard queries it back out — the same client-server relationship as any web app, database included.

Speaking your language: a LoRaWAN gateway is basically a reverse proxy for radio — it terminates a totally different protocol on one side (long-range, low-power radio) and speaks ordinary IP on the other, so everything past it looks like normal internet traffic.
Sources: NDSU Extension — "Basics of LoRa Technology for Crop and Livestock Management"; Campbell Scientific — Environmental Research dataloggers; METER Group, maker of agricultural soil sensors and dataloggers.
