Binary Search

Binary search finds a target value in a sorted array in O(log n) time by repeatedly cutting the search space in half, instead of checking every element one by one.

The idea

Look at the middle element of the array. If it's the target, you're done. If the target is smaller, it must be in the left half — discard the right half entirely. If it's larger, discard the left half. Repeat on the remaining half until the target is found or the search space is empty.

Each step throws away half of what's left, so for an array of size n, you need at most log₂(n) steps — roughly 20 steps for a million elements.

Implementation

def binary_search(arr, target):
    low, high = 0, len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1

numbers = [2, 5, 8, 12, 16, 23, 38, 45, 56, 72, 91]
print(binary_search(numbers, 23))   # -> 5
print(binary_search(numbers, 24))   # -> -1

Walkthrough

Searching for 23 in the array above (indices 0–10):

  1. low=0, high=10 → mid=5 → arr[5]=23. Match found immediately.

Searching for 45 instead:

  1. mid=5 → arr[5]=23, 45 > 23 → search right half, low=6
  2. mid=8 → arr[8]=56, 45 < 56 → search left half, high=7
  3. mid=6 → arr[6]=38, 45 > 38 → search right half, low=7
  4. mid=7 → arr[7]=45. Found at index 7.
Binary search only works if the array is already sorted. Running it on unsorted data gives incorrect results without any error — a common source of subtle bugs.

Complexity

  • Time: O(log n)
  • Space: O(1) for the iterative version above; O(log n) for a recursive version due to call stack depth.
