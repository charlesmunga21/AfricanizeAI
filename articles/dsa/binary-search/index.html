Binary Search

Binary search finds a value in a sorted array in O(log n) time by repeatedly cutting the search space in half, instead of checking every element one by one. It's the algorithm every efficient lookup — dictionaries, database indexes, version-control bisection — is a variation of.

This module covers the standard algorithm, the iterative-vs-recursive tradeoff, the most common real-world variant (finding a boundary in data with duplicates), and the complexity payoff that makes all of it worth doing.

  • The core idea: eliminate half the remaining search space with every comparison
  • Why the recursive version costs O(log n) extra space and the iterative one doesn't
  • How to find the first or last occurrence of a value when duplicates exist
  • Just how large the O(n) vs O(log n) gap gets as data grows
