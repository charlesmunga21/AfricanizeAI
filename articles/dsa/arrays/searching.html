Searching: Linear & Binary

Finding whether a value exists in an array — and at what index — has two standard approaches, and which one you can use depends entirely on whether the data is sorted.

Linear search

Check every element in order until you find the target or run out of elements. It works on any array, sorted or not, but in the worst case (target absent, or at the very end) it checks all n elements: O(n).

def linear_search(arr, target):
    for i, value in enumerate(arr):
        if value == target:
            return i
    return -1

Binary search

If the array is sorted, you don't need to check every element. Compare the target to the middle element: if it matches, done. If the target is smaller, it can only be in the left half; if larger, only the right half. Either way, you just eliminated half the remaining elements in one comparison. Repeating this gives O(log n) — for a million elements, about 20 comparisons instead of up to a million.

def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
Binary search's requirement — sorted data — isn't free. If the array changes often, keeping it sorted (or sorting it once, O(n log n)) has to be worth the repeated O(log n) searches it buys you. For a one-off search on unsorted data, linear search is simpler and just as fast in practice.
