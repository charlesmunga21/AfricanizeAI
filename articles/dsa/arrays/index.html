Arrays

An array is a collection of elements stored in contiguous memory locations, all of the same type, and accessed using an index. It's the simplest possible way to group values together, and almost every other data structure — lists, stacks, queues, hash tables — is built on top of one.

This module breaks arrays down the way a full course would: how they're addressed in memory, what each operation actually costs, how to search them efficiently, and how the same idea extends to more than one dimension. Every submodule has a small interactive model to poke at, and a short quiz to check what stuck.

Quick reference

OperationComplexityWhy
Access by indexO(1)Address is computed directly, no traversal
Search, unsortedO(n)Every element may need checking
Search, sorted (binary)O(log n)Each comparison halves the remaining range
Insert/delete at endO(1)No elements need to shift
Insert/delete at start or middleO(n)Every following element shifts to stay contiguous
