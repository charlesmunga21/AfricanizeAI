Linked Lists

A linked list stores a sequence of elements the way arrays do, but without requiring contiguous memory. Each element ("node") holds its value plus a pointer to the next node — the list itself only needs to remember where the first node ("head") lives.

Linked lists are the array's mirror image: everything that's expensive for an array (insert/delete away from the end) is cheap here, and everything that's cheap for an array (access by index) is expensive here. This module covers the structure, the operations, a direct side-by-side against arrays, and why linked lists can never binary search.
